隐私政策

最后更新: 2026年11月12日

Inkpane 在你的 Mac 上运行。你的截图、录屏、从中识别出的文字，以及资料库中的其他内容都保存在你的 Mac 上，我们从不会收到。 本政策说明数据确实会离开你的 Mac 的少数几种情况，以及原因。

本政策适用于 macOS 版 Inkpane 应用（「本应用」）和网站 inkpane.app。两者均由 Inkpane 的独立开发者（「Inkpane」「我们」）制作。如有问题或请求，请联系：support@inkpane.app。

简要说明

  • 没有账户，没有云端资料库，没有广告，没有跟踪，App 和网站里也没有分析统计。我们的下载服务器只统计总数（见「检查更新」）。我们不出售数据。
  • 截图、录屏、OCR 文字和资料库数据库永远不会离开你的 Mac，除非你自己把它们发送到某处，或由你设置的 AI Agent 或 AI 服务商接收。
  • 本应用会联系我们的下载服务器检查更新；在你拥有许可证后，还会联系我们的许可证服务校验许可证。除此之外，不会向我们发送任何内容。

保存在你 Mac 上的内容

以下所有内容只存储在你的 Mac 上、你的用户文件夹中。我们没有其中任何内容的副本。

  • 截图和录屏：截图、可附带麦克风声音的录屏、GIF、贴图以及标注文件。默认存放在 ~/Library/Application Support/app.inkpane.Inkpane/，或你选择的文件夹中。
  • 资料库：记录你所有截图的数据库。对每一项截图，它会保存文件位置、大小、日期、来源应用和窗口、浏览器地址（适用于 Safari、Chrome、Arc、Brave 和 Edge）、Git 项目、分支和远程仓库（已去除凭据）、标签、备注，以及从图像中识别出的文字。文字识别使用 Apple 在设备端运行的 Vision 框架。
  • 设置、日志和诊断信息：你的偏好设置、本应用自身的日志、macOS 生成的崩溃和性能报告、你允许的 AI Agent 列表，以及它们所请求内容的日志（最新的 500 条）。
  • 钥匙串项目：你的许可证记录，以及你为 AI 服务输入的 API Key，仅保存在这台 Mac 的 macOS 钥匙串中。许可证记录包含你 Mac 硬件 ID 的单向哈希值，用于发现被复制到另一台 Mac 上的许可证，且永远不会被发送到任何地方。

未固定的截图会在你选择的期限（7 天、30 天或永不）之后移到 macOS 废纸篓。如需删除全部内容，请退出本应用，然后删除上述文件夹、本应用，以及名为 app.inkpane.Inkpane.license 和 app.inkpane.Inkpane.ai 的钥匙串项目。

数据何时会离开你的 Mac

检查更新

本应用会向 downloads.inkpane.app 询问是否有新版本。如果你允许（设置 → 通用），它会自动检查；你选择「检查更新…」时也会检查。在 Pro 免费期间，本应用还会从同一服务器读取当前日期，这样优惠何时结束就不会只取决于你 Mac 的时钟。

和任何网络请求一样，这些请求会带有你的 IP 地址以及本应用的名称和版本。该服务器托管在 Cloudflare 上，Cloudflare 可能会依据其自己的隐私政策保留短期日志。我们的下载服务器只按总数统计这些请求以及本应用的下载：有多少次、是哪个版本、来自哪个国家或地区。为了统计每天有多少台 Mac 在使用本应用，服务器还会保存 IP 地址的单向哈希值，这个哈希值每天都会变化。IP 地址本身从不保存，不同日期的哈希值也无法相互关联。这些统计数据保留三个月。我们不建立用户画像。不会发送任何系统信息。

许可证

许可证尚未开售。开售后，购买将通过一家作为记录商户（merchant of record）的支付服务商进行，由其依据自己的隐私政策处理你的付款、发票、电子邮件地址和税务。开售时，我们会在这里写明该服务商，并公布购买条款。我们会收到为你提供支持所需的订单信息，例如你的电子邮件地址、所购产品和许可证密钥，但绝不会收到你的银行卡信息。

当你激活密钥时，本应用会将密钥和你的 Mac 名称（即在 系统设置 → 通用 → 共享 中设置的名称）发送给许可证服务。之后，它大约每天校验一次许可证，并在你「停用此 Mac」时释放这次激活。

你开启的 AI 功能

AI 快捷操作，以及使用 AI 服务或 DeepL 的翻译，在你添加自己的 API Key 之前都处于关闭状态。当你使用其中某项功能时，本应用会将请求从你的 Mac 直接发送给你选择的服务商：Anthropic、OpenAI 或其他兼容 OpenAI 的服务，或 DeepL。请求从不经过我们。

一次请求可能包含图像（除非你关闭图像发送）、从中识别出的文字、来源应用和窗口、页面地址以及你的提示词。如果你在 设置 → 隐私 中开启相应选项，电子邮件地址和电话号码会先被打码。服务商收到的内容适用其自己的条款和隐私政策。

Apple Intelligence 模型和 Apple 翻译在你的 Mac 上运行。Ollama 或 LM Studio 等本地服务器也同样留在你的 Mac 上。

你连接的 AI Agent

Inkpane 内置一个本地服务器（MCP），可供你 Mac 上的 AI Agent（例如 Claude Code 或 Codex）使用。它只接受来自你在这台 Mac 上的用户账户的连接，连接须通过受保护的本地套接字，或通过 127.0.0.1 并携带秘密令牌。

每个 Agent 都必须先获得允许，才能看到任何内容。它第一次请求时，你可以选择「允许一次」「始终允许」或「拒绝」，之后也可以在 设置 → 隐私 中撤销。Agent 工作时，屏幕顶部会显示指示标志，每个请求都会写入本地日志。

你允许的 Agent 可以截图、读取窗口的文字和辅助功能结构、列出窗口、读取资料库中的近期项目（包括其应用、标题、地址和 Git 项目）、录制屏幕，以及在屏幕上绘制。排除列表中的应用对 Agent 隐藏：默认包括密码管理器、银行和支付应用以及聊天应用。可选的电子邮件、电话号码和密码栏打码，同样适用于 Agent 收到的内容。

Agent 收到的内容可能会被转发给该 Agent 自己的 AI 服务商，并适用该 Agent 的条款。Inkpane 无法控制这一点，因此请只允许你信任的 Agent。

电子邮件

如果你给我们发邮件，我们只会将你的邮件内容和邮箱地址用于回复和帮助你，并且只在为此所需的期限内保留。

本应用请求的权限

  • 屏幕录制（必需）：用于截图和录屏，以及为你允许的 Agent 截取屏幕。
  • 辅助功能（可选）：用于找到需要打码的密码栏、为 Agent 读取窗口的辅助功能结构、识别你编辑器中打开的项目，以及在录屏中显示你按下的按键。按键只会出现在该录屏的画面中，不会被记录。
  • 麦克风（可选）：用于在录屏时录下你的声音。
  • 浏览器自动化（按浏览器分别请求）：用于在你截取浏览器时读取最前面标签页的地址。

本应用不使用你的摄像头或位置信息。

网站

inkpane.app 托管在 GitHub Pages 上。它不使用 Cookie，不使用分析统计，也不使用第三方脚本或字体。你选择的浅色或深色模式保存在浏览器的本地存储中，永远不会被发送。GitHub 以及（就下载而言）Cloudflare 可能会依据其自己的政策记录 IP 地址等技术数据。我们的下载服务器会按「检查更新」中所述的方式统计每次下载。

共享

我们不出售、出租或共享个人信息。数据只会按上文所述到达他人那里：你选择的 AI 服务商和 Agent、处理购买的支付服务商，以及我们的托管服务商。

你的权利

你的大部分数据都在你的 Mac 上，由你掌控，你可以随时查看、导出或删除。对于我们或我们的服务商持有的与你有关的任何信息，例如购买记录或邮件，请写信至 support@inkpane.app。你可以要求访问、更正或删除这些信息，我们会在 30 天内答复。

这些权利来自 New Zealand Privacy Act 2020（新西兰《2020 年隐私法》），以及在适用于你的情况下，GDPR（《通用数据保护条例》）等法律。你也可以向新西兰隐私专员办公室或你当地的数据保护机构投诉。

Inkpane 不面向 16 岁以下的儿童。

变更

如果本政策有变更，我们会更新顶部的日期。如果变更影响到哪些数据会离开你的 Mac，我们还会在本应用的版本说明中说明。

本政策也提供其他语言版本。如果译文与英文版本不一致，以英文版本为准，除非你所在地的法律另有规定。
