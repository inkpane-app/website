iPhone 与 iPad

iPhone、iPad 也能画。

Mac 上显示的任何画面，Inkpane 都能在上面画，iPhone 和 iPad 的屏幕也一样。可以标注 App 演示，录一段边讲边画的教程，也可以在真机上圈出 Bug 交给 Agent。

随航

把 iPad 当作 Mac 的第二块屏幕。Inkpane 像对待其他显示器一样，在上面画、打聚光灯、录屏。

iPhone 镜像

iPhone 会以窗口形式出现在 Mac 上。把标注固定到这个窗口，窗口移动时标注也跟着走。

数据线 + QuickTime

插上 iPhone 或 iPad，在 QuickTime 的影片录制里把它选为屏幕来源，就能连同你的标注一起录下它的屏幕。

iOS 模拟器

开发时直接在模拟器上标注和录屏。做 App 演示、评审和 Bug 报告都很方便。

iPhone 和 iPad 上什么都不用装。Inkpane 运行在 Mac 上，在 Mac 显示它们屏幕的地方作画。

为 Agent 打造

给 Agent 一双眼睛和一支笔。

一个本地 MCP 服务，Claude Code、Codex、Cursor 以及任何 MCP 客户端都能直接连上。

  • capture_screen截取屏幕、窗口或区域
  • read_screen_ocr本机识别文字及其位置
  • wait_for_user_annotation请你圈出某处，并等待
  • annotate_screen在你的屏幕上画框、箭头和备注
  • get_ui_tree读取窗口的辅助功能树
  • record_action边工作边录下复现过程

常见问题。

支持哪些 Agent？

Claude Code 和 Codex，在 设置 → Agents 里一键配置。Cursor、Claude Desktop 等任何支持 MCP 的客户端都能用同一个服务。

我的屏幕会被上传吗？

不会。Inkpane 完全在你的 Mac 上运行。截图只会在你或你批准过的 Agent 请求时交给它；只有你使用快捷操作时，才会发给你选的 AI 服务。

需要什么系统？

macOS 14 Sonoma 及以上，Apple 芯片或 Intel 均可。Apple 翻译等部分功能需要 macOS 15。

有 iPhone 或 iPad 版吗？

没有，也不需要。Inkpane 运行在 Mac 上，可以在 Mac 显示的 iPhone 和 iPad 屏幕上作画，方式有随航、iPhone 镜像、数据线加 QuickTime，以及 iOS 模拟器。

和 CleanShot X 有什么不同？

Inkpane 也有完整的截图功能，但它围绕 Agent 打造：Agent 能看到你圈的地方，也能画回你的屏幕上。

怎么更新？

Inkpane 会自动检查更新，安装前会先问你。
