常见问题

支持哪些 AI Agent？

首先支持 Claude Code 与 Codex，并计划提供一键配置。其他支持 MCP 的客户端（Cursor、Claude Desktop 等）也能使用同一个服务。

我的屏幕内容会被上传吗？

不会。Inkpane 完全在你的 Mac 上运行。只有在你或已获授权的 Agent 主动请求时，截图才会交给该 Agent。

运行需要什么环境？

macOS 14 Sonoma 及以上，支持 Apple 芯片与 Intel。部分增强功能（如端侧翻译）需要更新的 macOS 版本。

和 CleanShot X 有什么区别？

Inkpane 覆盖截图的基本功能，但核心围绕 Agent 设计：Agent 能看到你圈出的内容，也能在你的屏幕上画回来。录屏时还能实时标注。

如何更新？

Inkpane 会自动检查更新，安装前会先征求你的同意；也可以随时选择「检查更新…」手动检查。

在你的 Mac 上试试

安装 Inkpane，在设置里把它添加到 Claude Code 或 Codex，然后圈出你的第一个 bug。
