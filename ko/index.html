iPhone 및 iPad

iPhone과 iPad에서도.

Inkpane은 Mac에 보이는 모든 것 위에 그릴 수 있습니다. iPhone이나 iPad 화면도 마찬가지입니다. 앱 데모에 표시를 하고, 실시간 잉크로 사용 과정을 녹화하고, 실제 기기에서 발견한 버그에 동그라미를 쳐 에이전트에게 보여 주세요.

Sidecar

iPad를 보조 디스플레이로 사용하세요. Inkpane은 다른 화면과 똑같이 다루므로 그 위에 그리고, 스포트라이트를 비추고, 녹화할 수 있습니다.

iPhone 미러링

iPhone이 Mac의 윈도우로 열립니다. 표시를 그 윈도우에 붙이면 윈도우와 함께 움직입니다.

케이블 + QuickTime

iPhone이나 iPad를 연결하고 QuickTime 동영상 녹화에서 화면으로 선택하세요. 그런 다음 잉크를 얹은 채로 그 화면을 녹화하세요.

iOS 시뮬레이터

앱을 빌드하는 동안 시뮬레이터에 주석을 달고 녹화하세요. 앱 데모, 리뷰, 버그 리포트에 유용합니다.

iPhone이나 iPad에는 아무것도 설치할 필요가 없습니다. Inkpane은 그 화면이 표시되는 Mac에서 실행됩니다.

에이전트용

에이전트에게 눈과 펜을.

Claude Code, Codex, Cursor 등 모든 MCP 클라이언트가 바로 사용할 수 있는 로컬 MCP 서버입니다.

  • capture_screen화면, 윈도우 또는 영역
  • read_screen_ocr기기에서 인식한 텍스트와 위치
  • wait_for_user_annotation동그라미를 쳐 달라고 요청하고 기다립니다
  • annotate_screen화면 위의 상자, 화살표, 메모
  • get_ui_tree윈도우의 손쉬운 사용 트리
  • record_action작업하는 동안 재현 과정을 녹화합니다

Claude Code에 추가하기

$ claude mcp add inkpane -- inkpane-mcp

또는 설정 → 에이전트에서 클릭 한 번으로.

MCP 코어는 MIT 라이선스의 오픈 소스입니다.

개인정보 보호

설계부터 프라이빗하게.

화면은 Mac에서 가장 개인적인 것입니다. Inkpane은 사용자가 선택하지 않은 곳으로 화면을 절대 보내지 않습니다.

내 Mac에서.

캡처, OCR, 검색, Apple 번역은 모두 기기에서 실행됩니다. 계정도 클라우드도 없으며, 캡처가 저희에게 전송되지 않습니다.

모든 에이전트는 내가 승인.

각 MCP 클라이언트는 한 번 허락을 구하며, 화면을 보고 있을 때마다 화면 상단에 표시가 나타납니다.

민감한 앱은 제외.

에이전트는 기본적으로 암호 관리자, 은행, 채팅 앱을 볼 수 없습니다. 이메일과 전화번호는 자동으로 가릴 수 있습니다.

내 키, 내가 고른 제공자.

AI 동작은 키체인에 보관된 내 API 키를 사용합니다. 재판매 토큰은 없습니다.

자주 묻는 질문.

어떤 에이전트와 함께 쓸 수 있나요?

Claude Code와 Codex는 설정 → 에이전트에서 클릭 한 번으로 설정됩니다. Cursor, Claude Desktop 등 MCP를 지원하는 모든 클라이언트도 같은 서버를 사용할 수 있습니다.

내 화면이 어딘가에 업로드되나요?

아니요. Inkpane은 전적으로 Mac에서 실행됩니다. 캡처는 사용자나 에이전트가 요청할 때 승인한 에이전트에게만 전달되며, AI 제공자에게는 빠른 동작을 실행할 때만 전송됩니다.

무엇이 필요한가요?

Apple 실리콘 또는 Intel 기반의 macOS 14 Sonoma 이상이 필요합니다. Apple 번역 등 일부 부가 기능은 macOS 15가 필요합니다.

iPhone이나 iPad 앱이 있나요?

없으며, 필요하지도 않습니다. Inkpane은 Mac에서 실행되며 Sidecar, iPhone 미러링, 케이블과 QuickTime, 또는 iOS 시뮬레이터를 통해 Mac에 표시된 iPhone과 iPad 화면 위에 그립니다.

CleanShot X와 무엇이 다른가요?

Inkpane은 캡처의 기본기를 모두 갖추고 있지만, 에이전트를 중심으로 만들어졌습니다. 에이전트는 사용자가 동그라미 친 곳을 보고 화면 위에 다시 그려 답합니다.

업데이트는 어떻게 하나요?

Inkpane이 스스로 업데이트를 확인하고, 설치하기 전에 먼저 물어봅니다.

말하지 말고, 보여 주세요.

무료로 다운로드하세요. 에이전트에 추가하고 첫 번째 버그에 동그라미를 쳐 보세요.
