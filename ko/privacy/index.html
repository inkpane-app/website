개인정보 처리방침

최종 업데이트: 2026년 11월 11일

Inkpane은 사용자의 Mac에서 작동합니다. 캡처, 녹화, 그 안에서 인식된 텍스트, 그 밖의 보관함 내용은 사용자의 Mac에 남아 있으며, 저희는 이를 전혀 받지 않습니다. 이 방침은 데이터가 Mac 밖으로 나가는 몇 가지 경우와 그 이유를 설명합니다.

이 방침은 macOS용 Inkpane 앱(이하 “앱”)과 웹사이트 inkpane.app에 적용됩니다. 둘 다 Inkpane의 독립 개발자(이하 “Inkpane” 또는 “저희”)가 만들었습니다. 문의 및 요청: support@inkpane.app.

요약

  • 계정, 클라우드 보관함, 분석, 광고, 추적이 없습니다. 저희는 데이터를 판매하지 않습니다.
  • 캡처, 녹화, OCR 텍스트, 보관함 데이터베이스는 사용자가 직접 어딘가로 보내거나, 사용자가 설정한 AI 에이전트나 AI 제공자가 받는 경우가 아니면 Mac 밖으로 나가지 않습니다.
  • 앱은 업데이트를 확인하기 위해 저희 다운로드 서버에 접속하고, 라이선스가 있는 경우 라이선스를 확인하기 위해 저희 라이선스 서비스에 접속합니다. 그 밖에 저희에게 전송되는 것은 없습니다.

Mac에 남아 있는 것

다음 항목은 모두 사용자의 Mac, 사용자 폴더 안에만 저장됩니다. 저희는 그 어떤 사본도 가지고 있지 않습니다.

  • 캡처 및 녹화: 스크린샷, 선택적으로 마이크 소리를 포함하는 화면 녹화, GIF, 핀, 주석 파일. 기본적으로 ~/Library/Application Support/app.inkpane.Inkpane/ 또는 사용자가 선택한 폴더에 저장됩니다.
  • 보관함: 캡처에 관한 데이터베이스. 각 캡처마다 파일 위치, 크기, 날짜, 캡처한 앱과 윈도우, 브라우저 주소(Safari, Chrome, Arc, Brave, Edge의 경우), Git 프로젝트, 브랜치, 원격 저장소(자격 증명은 제거됨), 태그, 메모, 이미지에서 인식된 텍스트를 담고 있습니다. 텍스트 인식에는 Apple의 기기 내 Vision 프레임워크를 사용합니다.
  • 설정, 로그 및 진단 정보: 환경설정, 앱 자체 로그, macOS의 충돌 및 성능 보고서, 사용자가 허용한 AI 에이전트 목록, 그리고 에이전트가 요청한 내용의 기록(최신 500개 항목).
  • 키체인 항목: 라이선스 기록과 사용자가 AI 서비스용으로 입력한 API 키. 이 Mac의 macOS 키체인에만 저장됩니다. 라이선스 기록에는 Mac 하드웨어 ID의 단방향 해시가 포함됩니다. 이는 라이선스가 다른 Mac으로 복사된 것을 알아차리는 데 사용되며, 어디로도 전송되지 않습니다.

고정되지 않은 캡처는 사용자가 선택한 기간(7일, 30일 또는 안 함)이 지나면 macOS 휴지통으로 이동합니다. 모든 데이터를 지우려면 앱을 종료한 뒤 위의 폴더, 앱, 그리고 app.inkpane.Inkpane.license 및 app.inkpane.Inkpane.ai라는 이름의 키체인 항목을 삭제하세요.

데이터가 Mac 밖으로 나가는 경우

업데이트 확인

앱은 downloads.inkpane.app에 새 버전이 있는지 묻습니다. 사용자가 허용한 경우(설정 → 일반) 자동으로 확인하며, 업데이트 확인…을 선택했을 때도 확인합니다. 무료 Pro 기간 동안에는 앱이 같은 서버에서 현재 날짜도 읽어 오므로, 혜택 종료 시점이 Mac의 시계에만 의존하지 않습니다.

이러한 요청에는 다른 모든 웹 요청과 마찬가지로 사용자의 IP 주소와 앱의 이름 및 버전이 포함됩니다. 서버는 Cloudflare에서 호스팅되며, Cloudflare는 자체 개인정보 처리방침에 따라 단기 로그를 보관할 수 있습니다. 저희는 업데이트 확인이나 다운로드가 몇 번 있었는지와 같은 합계만 봅니다. 프로필을 만들지 않습니다. 시스템 정보는 전송되지 않습니다.

라이선스

라이선스는 아직 판매되지 않습니다. 판매가 시작되면 구매는 판매 대행사(merchant of record) 역할을 하는 결제 서비스를 통해 이루어지며, 해당 결제 서비스가 자체 개인정보 처리방침에 따라 결제, 인보이스, 이메일 주소, 세금을 처리합니다. 판매를 시작할 때 이곳에 해당 결제 서비스를 명시하고 구매 약관을 공개합니다. 저희는 사용자를 지원하는 데 필요한 주문 정보(이메일 주소, 제품, 라이선스 키 등)를 받지만, 카드 정보는 절대 받지 않습니다.

키를 활성화하면 앱은 키와 Mac의 이름(시스템 설정 → 일반 → 공유에서 설정한 이름)을 라이선스 서비스로 보냅니다. 이후 약 하루에 한 번 라이선스를 확인하며, 이 Mac을 비활성화하면 해당 활성화를 해제합니다.

사용자가 켠 AI 기능

AI 빠른 동작, 그리고 AI 서비스나 DeepL을 이용한 번역은 사용자가 자신의 API 키를 추가하기 전까지 꺼져 있습니다. 이 기능을 사용하면 앱은 요청을 사용자의 Mac에서 사용자가 선택한 제공자로 직접 보냅니다. 제공자는 Anthropic, OpenAI 또는 그 밖의 OpenAI 호환 서비스, 또는 DeepL입니다. 요청은 절대 저희를 거치지 않습니다.

요청에는 이미지(이미지를 끄지 않은 경우), 이미지에서 인식된 텍스트, 캡처한 앱과 윈도우, 페이지 주소, 사용자의 프롬프트가 포함될 수 있습니다. 설정 → 개인정보 보호에서 켜 두면 이메일 주소와 전화번호가 먼저 가려집니다. 제공자가 받는 내용에는 해당 제공자의 약관과 개인정보 처리방침이 적용됩니다.

Apple Intelligence 모델과 Apple 번역은 사용자의 Mac에서 실행됩니다. Ollama나 LM Studio 같은 로컬 서버도 사용자의 Mac에 머무릅니다.

사용자가 연결한 AI 에이전트

Inkpane에는 Claude Code나 Codex 같은 Mac의 AI 에이전트가 사용할 수 있는 로컬 서버(MCP)가 포함되어 있습니다. 이 서버는 이 Mac의 사용자 본인 계정에서 오는 연결만, 보호된 로컬 소켓을 통하거나 비밀 토큰과 함께 127.0.0.1을 통해서만 받아들입니다.

각 에이전트는 무엇이든 보기 전에 먼저 허용을 받아야 합니다. 에이전트가 처음 요청하면 사용자가 한 번 허용, 항상 허용, 거부 중에서 선택하며, 나중에 설정 → 개인정보 보호에서 취소할 수 있습니다. 에이전트가 작업하는 동안에는 화면 상단에 표시가 나타나고, 모든 요청은 로컬 로그에 기록됩니다.

사용자가 허용한 에이전트는 스크린샷을 찍고, 윈도우의 텍스트와 손쉬운 사용 구조를 읽고, 윈도우 목록을 가져오고, 최근 보관함 항목(앱, 제목, 주소, Git 프로젝트 포함)을 읽고, 화면을 녹화하고, 화면 위에 그릴 수 있습니다. 제외 목록에 있는 앱은 에이전트에게 보이지 않습니다. 기본적으로 암호 관리자, 은행 및 결제 앱, 메시지 앱이 여기에 포함됩니다. 이메일, 전화번호, 암호 필드를 가리는 선택적 마스킹도 에이전트가 받는 내용에 적용됩니다.

에이전트가 받은 내용은 해당 에이전트의 약관에 따라 그 에이전트의 AI 제공자에게 다시 전송될 수 있습니다. Inkpane은 이를 통제할 수 없으므로, 신뢰하는 에이전트만 허용하세요.

이메일

저희에게 이메일을 보내시면, 저희는 메시지와 주소를 답장하고 도와드리는 데에만 사용하며, 그에 필요한 기간 동안만 보관합니다.

앱이 요청하는 권한

  • 화면 기록(필수): 캡처와 녹화를 하고, 사용자가 허용한 에이전트를 위해 캡처하는 데 필요합니다.
  • 손쉬운 사용(선택): 가릴 암호 필드를 찾고, 에이전트를 위해 윈도우의 손쉬운 사용 구조를 읽고, 편집기에서 열려 있는 프로젝트를 인식하고, 녹화에서 누른 키를 표시하는 데 사용합니다. 키 입력은 해당 녹화의 화면에만 나타나며 기록되지 않습니다.
  • 마이크(선택): 화면 녹화와 함께 사용자의 음성을 녹음하는 데 사용합니다.
  • 브라우저 자동화(브라우저별로 요청): 캡처할 때 맨 앞 탭의 주소를 읽는 데 사용합니다.

앱은 카메라나 위치 정보를 사용하지 않습니다.

웹사이트

inkpane.app은 GitHub Pages에서 호스팅됩니다. 쿠키, 분석 도구, 타사 스크립트나 글꼴을 사용하지 않습니다. 라이트 모드 또는 다크 모드 선택은 브라우저의 로컬 저장소에 보관되며 전송되지 않습니다. GitHub, 그리고 다운로드의 경우 Cloudflare는 자체 정책에 따라 IP 주소 같은 기술 데이터를 기록할 수 있습니다.

공유

저희는 개인정보를 판매, 대여하거나 공유하지 않습니다. 데이터는 위에서 설명한 경우에만 다른 곳에 전달됩니다. 즉, 사용자가 선택한 AI 제공자와 에이전트, 구매를 위한 결제 서비스, 그리고 저희 호스팅 제공업체입니다.

사용자의 권리

데이터 대부분은 사용자의 Mac에 있고 사용자가 관리하므로, 언제든지 보고, 내보내고, 삭제할 수 있습니다. 구매 기록이나 이메일처럼 저희나 저희 제공업체가 보유한 사용자에 관한 정보에 대해서는 support@inkpane.app으로 연락해 주세요. 해당 정보의 열람, 정정 또는 삭제를 요청할 수 있으며, 저희는 30일 이내에 답변합니다.

이러한 권리는 New Zealand Privacy Act 2020(뉴질랜드 개인정보 보호법)과, 사용자에게 적용되는 경우 GDPR(EU 일반 개인정보 보호법) 같은 법률에 근거합니다. 뉴질랜드 개인정보 보호 위원회 사무국(Office of the Privacy Commissioner)이나 사용자 거주지의 데이터 보호 기관에 민원을 제기할 수도 있습니다.

Inkpane은 16세 미만 아동을 대상으로 하지 않습니다.

변경

이 방침이 변경되면 상단의 날짜를 업데이트합니다. 변경 사항이 Mac 밖으로 나가는 데이터에 영향을 주는 경우, 앱의 릴리스 노트에도 이를 밝힙니다.

이 방침은 다른 언어로도 제공됩니다. 번역본이 영어판과 다른 경우, 사용자 거주지의 법률이 달리 정하지 않는 한 영어판이 우선합니다.
