iPhone 與 iPad

iPhone、iPad 也能畫。

Mac 上顯示的任何畫面，Inkpane 都能在上面畫，iPhone 和 iPad 的螢幕也一樣。你可以標註 App 示範、錄一段邊講邊畫的操作教學，或在實機上圈出 Bug 交給 Agent。

並行

把 iPad 當成 Mac 的第二台顯示器。Inkpane 會像對待其他螢幕一樣，在上面繪製、打聚光燈和錄影。

iPhone 鏡像輸出

iPhone 會以視窗的形式出現在 Mac 上。把標註固定在這個視窗上，視窗移動時標註也會跟著走。

傳輸線 + QuickTime

接上 iPhone 或 iPad，在 QuickTime 的影片錄製中把它選為螢幕來源，就能連同你的筆跡一起錄下它的畫面。

iOS 模擬器

開發時直接在模擬器上標註和錄影。做 App 示範、審查和 Bug 回報都很方便。

iPhone 和 iPad 上什麼都不用安裝。Inkpane 在 Mac 上執行，直接畫在 Mac 顯示它們螢幕的地方。

為 Agent 打造

給 Agent 一雙眼睛和一支筆。

一個本機 MCP 伺服器，Claude Code、Codex、Cursor 以及任何 MCP 用戶端都能直接連上。

  • capture_screen擷取螢幕、視窗或區域
  • read_screen_ocr在本機辨識文字及其位置
  • wait_for_user_annotation請你圈出某個地方，並等待
  • annotate_screen在你的螢幕上畫框、箭頭和註解
  • get_ui_tree讀取視窗的輔助使用樹狀結構
  • record_action邊工作邊錄下重現過程

隱私權

從設計開始就重視隱私。

螢幕是你 Mac 上最私密的東西。沒有你的同意，Inkpane 絕不會把它傳到任何地方。

全都在你的 Mac 上。

截圖、OCR、搜尋和 Apple 翻譯都在本機完成。不用帳號，沒有雲端，你的截圖絕不會傳到我們這裡。

每個 Agent 都要經過你同意。

每個 MCP 用戶端只會問一次；只要有 Agent 正在看你的螢幕，畫面上方就會顯示提示。

敏感 App 自動排除。

Agent 預設看不到密碼管理工具、銀行和聊天 App；電子郵件地址和電話號碼也可以自動遮蔽。

你的金鑰，你選的服務。

AI 功能使用你自己的 API 金鑰，保存在你的鑰匙圈裡。我們不轉售額度。

常見問題。

支援哪些 Agent？

Claude Code 和 Codex，在「設定」→「Agent」中一鍵就能設定。Cursor、Claude Desktop 等任何支援 MCP 的用戶端，也都能使用同一個伺服器。

我的螢幕會被上傳到任何地方嗎？

不會。Inkpane 完全在你的 Mac 上執行。只有在你或你同意過的 Agent 提出要求時，截圖才會交給該 Agent；只有在你執行快速動作時，才會傳給你選擇的 AI 服務。

需要什麼系統？

macOS 14 Sonoma 或以上版本，Apple 晶片或 Intel 皆可。Apple 翻譯等部分額外功能需要 macOS 15。

有 iPhone 或 iPad 版嗎？

沒有，也不需要。Inkpane 在 Mac 上執行，可以直接畫在 Mac 顯示的 iPhone 和 iPad 螢幕上，方式包括並行、iPhone 鏡像輸出、傳輸線加 QuickTime，以及 iOS 模擬器。

和 CleanShot X 有什麼不同？

Inkpane 也具備完整的基本截圖功能，但它是圍繞 Agent 打造的：Agent 能看到你圈起來的地方，也能畫回你的螢幕上。

要怎麼更新？

Inkpane 會自動檢查更新，安裝前會先問過你。
