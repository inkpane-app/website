隱私權政策

最後更新: 2026年11月12日

Inkpane 在你的 Mac 上運作。你的截圖、錄影、從中辨識出的文字，以及圖庫中的其他內容都保留在你的 Mac 上，我們絕不會收到。 本政策說明資料確實會離開你的 Mac 的少數幾種情況，以及原因。

本政策適用於 macOS 版 Inkpane App（「本 App」）以及網站 inkpane.app。兩者皆由 Inkpane 的獨立開發者（「Inkpane」、「我們」）製作。如有問題或要求，請聯絡：support@inkpane.app。

摘要

  • 沒有帳號、沒有雲端圖庫、沒有廣告、沒有追蹤，App 和網站中也沒有任何分析工具。我們的下載伺服器只會統計總數（請見「檢查更新」）。我們不販售資料。
  • 截圖、錄影、OCR 文字和圖庫資料庫絕不會離開你的 Mac，除非你自己將它們傳送到別處，或由你設定的 AI Agent 或 AI 服務供應商接收。
  • 本 App 會連線到我們的下載伺服器檢查更新；在你擁有授權後，也會連線到我們的授權服務來驗證授權。除此之外，不會傳送任何內容給我們。

保留在你 Mac 上的內容

以下所有內容都只儲存在你的 Mac 上、你的使用者資料夾中。我們沒有其中任何內容的副本。

  • 截圖與錄影：螢幕截圖、可選擇包含麥克風聲音的螢幕錄影、GIF、釘選圖片和標註檔案。預設存放在 ~/Library/Application Support/app.inkpane.Inkpane/，或你選擇的資料夾中。
  • 圖庫：你截圖的資料庫。每張截圖都會記錄檔案位置、大小、日期、來源 App 和視窗、瀏覽器網址（適用於 Safari、Chrome、Arc、Brave 和 Edge）、Git 專案、分支和遠端位址（已移除帳號密碼等憑證）、標籤、附註，以及從圖片中辨識出的文字。文字辨識使用 Apple 的裝置端 Vision 框架。
  • 設定、記錄與診斷資料：你的偏好設定、App 本身的記錄、來自 macOS 的當機與效能報告、你允許的 AI Agent 列表，以及它們提出要求的記錄（最新的 500 筆）。
  • 鑰匙圈項目：你的授權記錄，以及你為 AI 服務輸入的 API 金鑰，都只存放在這台 Mac 的 macOS 鑰匙圈中。授權記錄包含你 Mac 硬體 ID 的單向雜湊值，用來察覺授權被拷貝到另一台 Mac 的情況，絕不會被傳送到任何地方。

未固定的截圖會在你選擇的期限（7 天、30 天或永不）過後移到 macOS 的垃圾桶。若要移除所有內容，請結束 App，然後刪除上述資料夾、App，以及名為 app.inkpane.Inkpane.license 和 app.inkpane.Inkpane.ai 的鑰匙圈項目。

資料何時會離開你的 Mac

檢查更新

本 App 會詢問 downloads.inkpane.app 是否有新版本可用。如果你允許（「設定」→「一般」），它會自動檢查；或在你選擇「檢查更新」時檢查。在 Pro 免費期間，本 App 也會從同一台伺服器讀取目前日期，讓優惠的結束時間不會只取決於你 Mac 的時鐘。

這些要求和任何網路要求一樣，會帶有你的 IP 位址以及 App 的名稱和版本。伺服器由 Cloudflare 託管，Cloudflare 可能會依其自身的隱私權政策保留短期記錄。我們的下載伺服器對這些要求及 App 的下載次數只會統計總數：共有多少次、是哪個版本、來自哪個國家。為了統計每天有多少台 Mac 使用本 App，它也會保留 IP 位址的單向雜湊值，此雜湊值每天都會變更。IP 位址本身絕不會被儲存，不同日期的雜湊值也無法互相連結。這些統計數字會保留三個月。我們不會建立個人檔案，也不會傳送任何系統資訊。

授權

授權目前尚未開始販售。開始販售後，購買將透過一家擔任登記商家（merchant of record）的付款服務供應商進行，由其依自身的隱私權政策處理你的付款、發票、電子郵件地址和稅務。授權開始販售時，我們會在此公布其名稱，並發佈購買條款。我們會收到為你提供支援所需的訂單資訊，例如你的電子郵件地址、產品和授權金鑰，但絕不會收到你的信用卡資料。

當你啟用金鑰時，本 App 會將金鑰和你 Mac 的名稱（即「系統設定」→「一般」→「共享」中設定的名稱）傳送到授權服務。之後它大約每天會驗證一次授權，並在你停用這台 Mac 時釋出啟用名額。

你開啟的 AI 功能

AI 快速動作，以及使用 AI 服務或 DeepL 的翻譯功能，在你加入自己的 API 金鑰之前都是關閉的。當你使用其中一項功能時，本 App 會將要求直接從你的 Mac 傳送到你選擇的服務供應商：Anthropic、OpenAI 或其他與 OpenAI 相容的服務，或是 DeepL。要求絕不會經過我們。

一個要求可能包含圖片（除非你關閉圖片）、從中辨識出的文字、來源 App 和視窗、網頁網址，以及你的提示詞。如果你在「設定」→「隱私權」中開啟遮蔽功能，電子郵件地址和電話號碼會先被遮蔽。服務供應商收到的內容，適用該供應商自身的條款和隱私權政策。

Apple Intelligence 模型和 Apple 翻譯都在你的 Mac 上執行。Ollama 或 LM Studio 等本機伺服器也同樣留在你的 Mac 上。

你連接的 AI Agent

Inkpane 內含一個本機伺服器（MCP），供你 Mac 上的 AI Agent（例如 Claude Code 或 Codex）使用。它只接受來自這台 Mac 上你自己使用者帳號的連線，透過受保護的本機通訊端（socket），或透過帶有私密權杖的 127.0.0.1。

每個 Agent 都必須先經過允許，才能看到任何內容。它第一次提出要求時，你可以選擇「允許一次」、「永遠允許」或「拒絕」，之後也可以在「設定」→「隱私權」中撤銷。當 Agent 正在運作時，螢幕上方會顯示指示標誌，而且每個要求都會寫入本機記錄。

你允許的 Agent 可以擷取螢幕畫面、讀取視窗中的文字和輔助使用結構、列出視窗、讀取最近的圖庫項目（包括其 App、標題、網址和 Git 專案）、錄製螢幕，以及在螢幕上繪製。排除名單中的 App 會對 Agent 隱藏：預設包括密碼管理工具、銀行和付款 App，以及通訊 App。可選擇開啟的電子郵件地址、電話號碼和密碼欄位遮蔽功能，也同樣適用於 Agent 收到的內容。

Agent 收到的內容可能會依該 Agent 的條款，再傳送給該 Agent 自己的 AI 服務供應商。Inkpane 無法控制這一點，因此請只允許你信任的 Agent。

電子郵件

如果你寄電子郵件給我們，我們只會將你的訊息和地址用於回覆及協助你，並只在必要的期間內保留。

本 App 要求的權限

  • 螢幕錄製（必要）：用於截圖和錄影，以及為你允許的 Agent 擷取畫面。
  • 輔助使用（選用）：用於尋找需要遮蔽的密碼欄位、為 Agent 讀取視窗的輔助使用結構、辨識你編輯器中打開的專案，以及在錄影中顯示你按下的按鍵。按鍵只會出現在該段錄影的畫面中，不會被記錄。
  • 麥克風（選用）：用於在螢幕錄影時錄下你的聲音。
  • 瀏覽器的自動化（依瀏覽器分別詢問）：用於在你擷取最前方的分頁時讀取其網址。

本 App 不會使用你的相機或位置。

網站

inkpane.app 由 GitHub Pages 託管。網站不使用 Cookie、分析工具，也不使用任何第三方腳本或字體。你選擇的淺色或深色模式，以及你在選單中挑選的語言，會保存在你瀏覽器的本機儲存空間中，絕不會被傳送出去。在英文首頁上，網站會讀取你瀏覽器的偏好語言（只在你的瀏覽器中進行），以顯示該語言的版本。GitHub 以及（下載時的）Cloudflare 可能會依其自身的政策記錄 IP 位址等技術資料。我們的下載伺服器會依「檢查更新」中所述的方式統計每次下載。

分享

我們不會販售、出租或分享個人資訊。資料只會依上述方式送達他方：你選擇的 AI 服務供應商和 Agent、處理購買的付款服務供應商，以及我們的託管服務供應商。

你的權利

你的大部分資料都在你的 Mac 上並由你掌控，因此你可以隨時檢視、匯出或刪除。對於我們或我們的服務供應商所持有、與你相關的任何資料（例如購買記錄或電子郵件），請寫信至 support@inkpane.app。你可以要求存取、更正或刪除這些資料，我們會在 30 天內回覆。

這些權利來自紐西蘭《2020 年隱私法》（Privacy Act 2020），以及在適用於你的情況下，GDPR 等法律。你也可以向紐西蘭隱私專員辦公室（Office of the Privacy Commissioner）或你當地的資料保護主管機關提出申訴。

Inkpane 並非以未滿 16 歲的兒童為對象。

變更

如果本政策有所變更，我們會更新頂部的日期。如果變更會影響哪些資料離開你的 Mac，我們也會在 App 的版本說明中告知。

本政策也提供其他語言版本。若譯文與英文版本有所不同，以英文版本為準，除非你所在地的法律另有規定。
