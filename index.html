Eyes and a pen for your AI agent

Three things your agent can’t do from a terminal alone.

  • Draw anywhere, even while recording

    A transparent canvas over every app. Pen, arrows, boxes, highlights and spotlight. Fading ink for live explanations, persistent ink for notes — and it all ends up in your screen recordings.

  • Two-way MCP for Claude Code & Codex

    Your agent can capture a window, read text with on-device OCR, ask you to circle something and wait for it, then draw its own boxes and arrows back on your screen.

  • A screenshot inbox you can search

    Every capture — including ⌘⇧4 — lands in a local inbox with app, window and URL. Search by the text inside images. Pin what matters; the rest cleans itself up.

Local-first and private by default

Your screen is the most sensitive thing on your computer. Inkpane treats it that way.

Nothing leaves your Mac
Capture, OCR and search run on-device. There is no Inkpane server in the loop.
You approve every agent
Each MCP client asks for permission once, and a clear indicator shows whenever an agent is looking.
Sensitive apps stay hidden
Password managers, banking and chat apps are excluded by default. Add your own.
Bring your own model
Optional AI shortcuts use your own API key or on-device models. No resold tokens.

Questions

Which AI agents does it work with?

Claude Code and Codex first, with one-click setup planned. Anything that speaks MCP — Cursor, Claude Desktop and others — can use the same server.

Does my screen get uploaded anywhere?

No. Inkpane runs entirely on your Mac. Screenshots only go to an agent when you or that agent request it, and only after you have approved that agent.

What do I need to run it?

macOS 14 Sonoma or later, on Apple Silicon or Intel. Some extras, like on-device translation, need newer macOS versions.

How is this different from CleanShot X?

Inkpane covers the capture basics, but it is built around your agent: the agent can see what you circle and draw back on your screen. You can annotate live while recording, too.

How do updates work?

Inkpane checks for updates on its own and asks before installing one. You can also choose Check for Updates… at any time.
