iPhone と iPad

iPhone と iPad にも。

Inkpane は Mac に映るものなら何にでも描けます。iPhone や iPad の画面も同じです。アプリのデモに書き込んだり、描きながら操作手順を録画したり、実機のバグを囲んでエージェントに渡したり。

Sidecar

iPad を2台目のディスプレイとして使えます。Inkpane にとってはほかの画面と同じ。描画も、スポットライトも、録画も。

iPhone ミラーリング

iPhone が Mac のウインドウとして開きます。マークをそのウインドウに追従させれば、一緒に動きます。

ケーブル + QuickTime

iPhone や iPad をつなぎ、QuickTime のムービー収録で画面として選びます。あとは描いた線ごとその画面を録画できます。

iOS シミュレータ

開発しながらシミュレータに注釈を付けて録画。アプリのデモやレビュー、バグ報告に便利です。

iPhone や iPad には何もインストールする必要はありません。Inkpane は、それらの画面が映る Mac 上で動作します。

エージェント向け

エージェントに、目とペンを。

Claude Code、Codex、Cursor をはじめ、あらゆる MCP クライアントがそのまま使えるローカル MCP サーバ。

  • capture_screen画面、ウインドウ、または領域
  • read_screen_ocrテキストと位置をデバイス上で認識
  • wait_for_user_annotation何かを囲むよう頼み、待機
  • annotate_screen画面に枠、矢印、メモを描画
  • get_ui_treeウインドウのアクセシビリティツリー
  • record_action作業しながら再現手順を録画

プライバシー

設計からプライベート。

画面は、Mac の中でもっとも個人的なもの。Inkpane は、あなたが選んだ相手以外にそれを送ることはありません。

すべて Mac の中で。

キャプチャ、OCR、検索、Apple 翻訳はデバイス上で動作します。アカウントもクラウドもなく、キャプチャが私たちに届くことはありません。

エージェントは承認制。

MCP クライアントは最初に一度だけ許可を求め、見ている間は画面上部にバッジが表示されます。

機密アプリは対象外。

パスワードマネージャ、銀行、チャットのアプリは、デフォルトで Agent から見えません。メールアドレスや電話番号は自動でマスクできます。

自分のキー、自分のプロバイダ。

AIアクションには、キーチェーンに保管したあなた自身のAPIキーを使います。トークンの転売はありません。

よくある質問

どのエージェントで使えますか？

Claude Code と Codex は、「設定」→「エージェント」からワンクリックで設定できます。Cursor や Claude Desktop など、MCP に対応したものなら同じサーバを使えます。

画面がどこかにアップロードされますか？

いいえ。Inkpane は完全に Mac 上で動作します。キャプチャがエージェントに渡るのは、あなたが承認したエージェントに、あなたかエージェントが求めたときだけ。AIプロバイダに送られるのは、クイックアクションを実行したときだけです。

必要な環境は？

macOS 14 Sonoma 以降、Apple シリコンまたは Intel 搭載の Mac。Apple 翻訳など一部の機能には macOS 15 が必要です。

iPhone や iPad のアプリはありますか？

ありませんし、必要もありません。Inkpane は Mac 上で動作し、Mac に映した iPhone や iPad の画面に描けます。Sidecar、iPhone ミラーリング、ケーブルと QuickTime、または iOS シミュレータを使います。

CleanShot X とは何が違いますか？

Inkpane もキャプチャの基本機能は揃っていますが、中心にあるのはエージェントです。あなたが囲んだものをエージェントが見て、あなたの画面に描き返します。

アップデートはどうなりますか？

Inkpane は自動でアップデートを確認し、インストールする前に確認を求めます。
