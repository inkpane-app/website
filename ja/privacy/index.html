プライバシーポリシー

最終更新日: 2026年11月12日

Inkpane は Mac 上で動作します。キャプチャ、録画、そこから認識されたテキスト、その他のライブラリの内容はあなたの Mac に保存され、私たちが受け取ることはありません。 このポリシーでは、データが Mac の外に送られる数少ないケースと、その理由を説明します。

本ポリシーは、macOS 向け Inkpane アプリ（以下「本アプリ」）とウェブサイト inkpane.app を対象とします。いずれも Inkpane の個人開発者（以下「Inkpane」「私たち」）が制作しています。ご質問やご請求は support@inkpane.app までお寄せください。

概要

  • アカウント、クラウドライブラリ、広告、トラッキングは一切なく、アプリにもウェブサイトにもアクセス解析はありません。ダウンロードサーバは合計値だけを数えます（「アップデートの確認」を参照）。データを販売することもありません。
  • キャプチャ、録画、OCR テキスト、ライブラリのデータベースが Mac の外に出ることはありません。ただし、あなた自身がどこかへ送った場合や、あなたが設定した AI エージェントや AI プロバイダが受け取る場合は除きます。
  • 本アプリは、アップデートを確認するために私たちのダウンロードサーバに接続し、ライセンスをお持ちの場合はその確認のために私たちのライセンスサービスに接続します。それ以外に私たちへ送信されるものはありません。

Mac に保存されるもの

以下はすべて、あなたの Mac のユーザフォルダ内にのみ保存されます。私たちはそのいずれのコピーも持っていません。

  • キャプチャと録画：スクリーンショット、画面録画（マイク音声も含められます）、GIF、ピン、注釈ファイル。デフォルトの保存先は ~/Library/Application Support/app.inkpane.Inkpane/、またはあなたが選んだフォルダです。
  • ライブラリ：キャプチャのデータベースです。各キャプチャについて、ファイルの場所、サイズ、日付、取り込み元のアプリとウインドウ、ブラウザのアドレス（Safari、Chrome、Arc、Brave、Edge の場合）、Git のプロジェクト、ブランチ、リモート（認証情報は除去済み）、タグ、メモ、画像内から認識されたテキストを保持します。テキスト認識には、デバイス上で動作する Apple の Vision フレームワークを使用します。
  • 設定、ログ、診断情報：環境設定、本アプリ自身のログ、macOS によるクラッシュレポートとパフォーマンスレポート、あなたが許可した AI エージェントの一覧、そしてエージェントが要求した内容の記録（最新の 500 件）。
  • キーチェーン項目：ライセンス記録と、AI サービス用に入力した API キー。この Mac の macOS キーチェーンにのみ保存されます。ライセンス記録には、Mac のハードウェア ID の一方向ハッシュが含まれます。これはライセンスが別の Mac にコピーされたことを検知するために使われ、どこにも送信されることはありません。

ピン留めされていないキャプチャは、あなたが選んだ期間（7 日、30 日、または移動しない）が過ぎると macOS のゴミ箱に移動します。すべてを削除するには、本アプリを終了し、上記のフォルダ、本アプリ、そして app.inkpane.Inkpane.license と app.inkpane.Inkpane.ai という名前のキーチェーン項目を削除してください。

データが Mac の外に送られる場合

アップデートの確認

本アプリは、新しいバージョンがあるかどうかを downloads.inkpane.app に問い合わせます。許可している場合（設定 → 一般）は自動で、または「アップデートを確認…」を選んだときに確認します。無料 Pro 期間中は、オファーの終了があなたの Mac の時計だけに左右されないよう、同じサーバから現在の日付も取得します。

これらのリクエストには、ほかのウェブリクエストと同様に、あなたの IP アドレスと、本アプリの名前およびバージョンが含まれます。サーバは Cloudflare 上でホストされており、Cloudflare は同社のプライバシーポリシーに基づいて短期間のログを保持することがあります。ダウンロードサーバは、これらのリクエストとアプリのダウンロードを合計値としてのみ数えます。回数、バージョン、国や地域です。1 日に何台の Mac がアプリを使っているかを数えるため、サーバは IP アドレスの一方向ハッシュも保存します。このハッシュは毎日変わります。IP アドレスそのものは保存されず、異なる日のハッシュを結び付けることはできません。これらの集計は 3 か月間保持されます。プロファイルの作成は行いません。システム情報は送信されません。

ライセンス

ライセンスはまだ販売していません。販売開始後、購入は正式な販売者（Merchant of Record）となる決済サービスを通じて行われ、同社が自社のプライバシーポリシーに基づいて、お支払い、請求書、メールアドレス、税金を取り扱います。販売開始時に、その決済サービス名をここに記載し、購入条件を公開します。私たちは、メールアドレス、製品、ライセンスキーなど、サポートに必要な注文情報を受け取りますが、カード情報を受け取ることはありません。

キーを有効化すると、本アプリはキーとあなたの Mac の名前（システム設定 → 一般 → 共有 で設定されているもの）をライセンスサービスに送信します。その後は約 1 日に 1 回ライセンスを確認し、この Mac のライセンスを無効化したときには、そのアクティベーションを解放します。

オンにした AI 機能

AI クイックアクションと、AI サービスまたは DeepL による翻訳は、あなた自身の API キーを追加するまでオフになっています。これらを使うと、本アプリはリクエストをあなたの Mac から、あなたが選んだプロバイダへ直接送信します。送信先は Anthropic、OpenAI その他の OpenAI 互換サービス、または DeepL です。私たちを経由することはありません。

リクエストには、画像（オフにしていない場合）、画像内から認識されたテキスト、取り込み元のアプリとウインドウ、ページのアドレス、そしてあなたのプロンプトが含まれることがあります。設定 → プライバシー でオンにしている場合は、メールアドレスと電話番号が送信前にマスクされます。プロバイダが受け取ったものには、そのプロバイダ自身の利用規約とプライバシーポリシーが適用されます。

Apple Intelligence のモデルと Apple 翻訳は、あなたの Mac 上で動作します。Ollama や LM Studio などのローカルサーバも、Mac の外には出ません。

接続した AI エージェント

Inkpane には、Claude Code や Codex など、Mac 上の AI エージェントが利用できるローカルサーバ（MCP）が含まれています。このサーバが受け付けるのは、この Mac 上のあなた自身のユーザアカウントからの接続のみで、保護されたローカルソケット経由、または秘密のトークンを使った 127.0.0.1 経由に限られます。

各エージェントは、何かを見る前に許可を得る必要があります。初めて要求があったときに「1回だけ許可」「常に許可」「拒否」から選び、あとから 設定 → プライバシー で取り消すこともできます。エージェントが作業している間は画面上部にインジケータが表示され、すべてのリクエストがローカルのログに記録されます。

許可したエージェントは、スクリーンショットの撮影、ウインドウのテキストとアクセシビリティ構造の読み取り、ウインドウの一覧取得、最近のライブラリ項目（アプリ、タイトル、アドレス、Git プロジェクトを含む）の読み取り、画面の録画、画面への描画を行えます。除外リストにあるアプリはエージェントから隠されます。デフォルトでは、パスワードマネージャ、銀行や決済のアプリ、メッセージアプリが含まれます。メールアドレス、電話番号、パスワード欄の任意のマスクは、エージェントが受け取る内容にも適用されます。

エージェントが受け取った内容は、そのエージェントの規約に基づき、そのエージェント自身の AI プロバイダに送られることがあります。Inkpane はそれを制御できないため、信頼できるエージェントだけを許可してください。

メール

私たちにメールを送られた場合、そのメッセージとメールアドレスは、返信とサポートのためにのみ使用し、そのために必要な期間だけ保管します。

アプリが求めるアクセス許可

  • 画面収録（必須）：キャプチャや録画を行うため、また許可したエージェントのためにキャプチャを行うため。
  • アクセシビリティ（任意）：マスクするパスワード欄を見つけるため、エージェントのためにウインドウのアクセシビリティ構造を読み取るため、エディタで開いているプロジェクトを認識するため、そして録画中に押したキーを表示するため。キー入力はその録画の映像にのみ表示され、ログには記録されません。
  • マイク（任意）：画面録画と一緒にあなたの声を録音するため。
  • ブラウザのオートメーション（ブラウザごとに確認）：キャプチャするときに、最前面のタブのアドレスを読み取るため。

本アプリがカメラや位置情報を使用することはありません。

ウェブサイト

inkpane.app は GitHub Pages でホストされています。Cookie、アクセス解析、サードパーティのスクリプトやフォントは一切使用していません。ライトモードとダークモードの選択はブラウザのローカルストレージに保存され、送信されることはありません。GitHub、およびダウンロードについては Cloudflare が、それぞれのポリシーに基づいて IP アドレスなどの技術的なデータを記録することがあります。ダウンロードサーバは、「アップデートの確認」で説明した方法で各ダウンロードを数えます。

第三者との共有

私たちは個人情報を販売、貸与、共有しません。データが他者に渡るのは、上記で説明した場合に限られます。つまり、あなたが選んだ AI プロバイダとエージェント、購入時の決済サービス、そして私たちのホスティングプロバイダです。

あなたの権利

データのほとんどはあなたの Mac にあり、あなたの管理下にあるため、いつでも閲覧、書き出し、削除ができます。購入記録やメールなど、私たちまたは私たちのプロバイダが保有するあなたに関する情報については、support@inkpane.app までご連絡ください。その情報の開示、訂正、削除を求めることができ、私たちは 30 日以内に回答します。

これらの権利は、New Zealand Privacy Act 2020（ニュージーランド 2020 年プライバシー法）および、あなたに適用される場合は GDPR（EU 一般データ保護規則）などの法律に基づくものです。ニュージーランドのプライバシー・コミッショナー事務局（Office of the Privacy Commissioner）、またはお住まいの地域のデータ保護機関に苦情を申し立てることもできます。

Inkpane は 16 歳未満の子どもを対象としていません。

変更

本ポリシーを変更した場合は、冒頭の日付を更新します。Mac の外に送られるデータに影響する変更の場合は、本アプリのリリースノートでもお知らせします。
